# Uji Manual — Verifikasi Paket & Trial

## 1. Registrasi Trial
- Daftar akun client baru melalui halaman landing (trial otomatis 24 jam)

## 2. Isi Konten Undangan
- Lengkapi data pengantin, acara, galeri, cerita, dan kado
- Pastikan semua tersimpan dengan benar

## 3. Verifikasi Paket Basic
- Ubah status undangan client ke paket **Basic**
- Pastikan fitur yang tampil di panel client dan halaman publik **hanya** sesuai paket Basic:
  - Gallery: max 5 foto
  - Love story: tidak aktif
  - Custom music: tidak aktif

## 4. Verifikasi Paket Premium
- Ubah status undangan client ke paket **Premium**
- Pastikan fitur yang tampil sesuai paket Premium:
  - Gallery: max 10 foto
  - Love story: aktif
  - Custom music: tidak aktif

## 5. Verifikasi Paket VIP
- Ubah status undangan client ke paket **VIP**
- Pastikan semua fitur aktif dan gallery unlimited

## 6. Dashboard Client
- Perhatikan perbedaan tampilan dashboard client pada setiap paket

## 7. Manajemen Client (Admin)
- Pantau daftar client, status, dan paket di panel admin

## 8. Verifikasi Trial — Musik
- Status **trial** tidak bisa mengganti musik latar
- Pastikan ada keterangan/peringatan di menu **Pengaturan** undangan sisi client
